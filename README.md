# Claude Pro 價格：月付、年付與 Max 方案比較，先看官方費用再決定是否代訂

搜尋「Claude Pro 價格」的人，通常不只想知道每月要付多少，也想確認年付是否比較便宜、Pro 和 Max 差在哪裡，以及沒有海外信用卡時能不能完成訂閱。

目前 Anthropic 官方列出的個人方案包括 Free、Pro、Max 5x 和 Max 20x。Claude Pro 的官方價格是 **每月 20 美元**；選擇年付時，價格為 **每年 200 美元**，平均每月約 16.67 美元。實際結帳金額可能依地區、幣別與稅金有所不同。

如果你只想固定使用 Claude，Pro 通常已經是最容易理解的方案。Max 則是給每天大量使用、經常遇到用量限制，或需要比 Pro 更高使用容量的人。

## Claude Pro 月付與年付怎麼選？

### 月付：適合先試用或使用量不穩定的人

月付價格是每月 20 美元。它的優點是彈性較高，想用的月份再訂閱，不必一次支付整年的費用。

月付比較適合：

- 剛從免費版升級，還不確定使用頻率的人
- 只在特定專案期間使用 Claude 的人
- 需要先確認自己的帳號、地區與付款方式是否能正常使用的人
- 不想一次支付 200 美元的人

如果你只是偶爾整理文件、修改幾篇文章，免費版可能已經夠用。若你每週都會使用 Claude 寫作、閱讀資料或協助編程，Pro 的額度和功能才比較有意義。

### 年付：適合確定全年都會使用的人

Claude Pro 年付價格是 200 美元，官方標示相當於每月約 16.67 美元，比 12 個月月付的 240 美元少 40 美元。

但年付不是所有人都適合。你需要先確認：

1. 接下來一年是否真的會持續使用 Claude。
2. 自己所在的地區是否支援年付選項。
3. 年付是否能使用你需要的模型與功能。
4. 付款頁顯示的稅金和最終金額是多少。

若只是為了「平均每月比較便宜」就直接年付，結果三個月後不再使用，實際上仍然支付了一筆沒有用完的訂閱費。

## Pro 和免費版差在哪裡？

免費版可以用來試用 Claude 的基本對話、寫作、文件分析等能力，但使用額度有限。當你在短時間內進行多次對話、上傳較多文件，或處理較複雜的任務時，免費版比較容易碰到限制。

Claude Pro 主要增加的是：

- 更高的使用量
- Claude Code 存取權
- Projects 專案功能
- Research 研究功能
- Google Workspace 連接
- 更多模型選擇
- 複雜任務的 Extended Thinking
- 高流量時段的優先存取

這些功能對一般聊天不一定都必要。真正能感受到差異的使用情境，通常是長文件分析、持續修改同一個專案、程式開發，以及需要反覆來回討論的工作。

例如，你只是偶爾請 Claude 改寫一封電郵，免費版通常足夠。若你要它閱讀一份研究報告、整理多份資料，再根據前面內容反覆修改文章，Pro 的價值就比較明顯。

## Max 5x 和 Max 20x 值不值得？

Max 方案不是單純換一個模型名稱，而是提高使用容量。Anthropic 公開資料顯示，Max 5x 的使用容量約為 Pro 的 5 倍，Max 20x 則約為 Pro 的 20 倍。兩者價格分別是每月 100 美元和 200 美元。

可以先用以下方式判斷：

| 使用情況 | 較合理的選擇 |
| --- | --- |
| 偶爾問問題、改寫短文 | Free |
| 每週固定使用，偶爾處理長文件 | Pro |
| 每天長時間使用，常常遇到 Pro 額度限制 | Max 5x |
| Claude 是主要工作工具，幾乎每天高強度使用 | Max 20x |

如果你沒有實際遇到 Pro 的使用限制，直接購買 Max 通常很難證明差價合理。Max 5x 比 Pro 貴 80 美元，Max 20x 則貴 180 美元；這不是小額升級，而是完整的使用量級差異。

## 透過 BeWild 訂閱 Claude Pro 要注意什麼？

BeWild 的定位是協助使用者以微信或支付寶等方式完成 AI 服務訂閱。公開頁面列出 Claude Pro、Max 5x 和 Max 20x 等產品，並提供中文操作流程。

如果你沒有可用的海外信用卡，這類代訂服務可能比較方便。不過，方便不代表流程和官方訂閱完全相同。根據 BeWild 的 Claude 訂閱說明，使用者需要：

1. 在 BeWild 頁面選擇 Claude 和訂閱週期。
2. 登入自己的 Claude 帳號。
3. 使用 Cookie-Editor 匯出 Claude 網站的 Cookie JSON。
4. 將 Cookie 資料貼回訂閱流程。
5. 確認帳號與方案後付款。
6. 等待系統完成升級。

BeWild 的說明稱，付款後一般約需 5 至 30 分鐘完成開通，但實際時間仍可能受帳號狀態、網路與官方驗證影響。

### Cookie 是什麼？

Cookie 是瀏覽器保存的登入狀態資料。BeWild 的教學要求從已登入的 `claude.ai` 頁面匯出 Cookie，而不是從其他網站複製。這類資料具備帳號驗證作用，不應貼給無關的人，也不應在公共電腦上操作。

如果你不願意把登入狀態資料交給第三方，直接使用 Anthropic 官方訂閱會比較符合你的風險偏好。若你選擇代訂，至少要確認：

- 只在自己的裝置上操作。
- 只從已登入的 Claude 頁面匯出資料。
- 不要把 Cookie JSON 傳給私人客服或陌生人。
- 不要在付款前忽略方案名稱與訂閱週期。
- 開通後立即確認 Claude 帳號中的方案狀態。
- 不要在同一筆訂單未完成前重複付款。

## BeWild 的多月訂閱和官方年付一樣嗎？

不一定。

Anthropic 官方提供 Pro 年付方案，價格是每年 200 美元。BeWild 的說明則提到，平台可能提供 2 個月或 3 個月的長期訂閱，部分流程會先將多月費用預存至平台帳戶，再依月份處理續訂。

這種第三方多月方案不能直接視為 Anthropic 官方年付。兩者至少有幾個差異：

- 官方年付由 Anthropic 直接收取。
- BeWild 多月方案由第三方平台處理付款與履約。
- 官方年付的退款與取消規則由 Anthropic 管理。
- BeWild 訂單則要依平台的履約與退款規則處理。
- 多月代訂方案可能要求不要在 Claude 官方頁面自行取消，否則後續月份可能無法繼續生效。

因此，選擇前應先看清楚頁面標示的是「單月訂閱」、「多月訂閱」還是「官方年付」。名稱相近，付款與續期方式可能完全不同。

## Claude Pro 價格怎麼算才公平？

比較價格時，不要只看「每月多少美元」。至少要把以下幾項分開：

### 1. 官方訂閱費

Claude Pro 官方月付是 20 美元，年付是 200 美元。這是 Anthropic 公開的基準價格。

### 2. 稅金和地區價格

Anthropic 說明，部分地區會以當地貨幣顯示價格，稅金可能已包含在頁面價格中，也可能在結帳時另外計算。

### 3. 第三方服務費

如果透過代訂平台付款，實付金額可能高於官方價格。差額可能來自支付通道、人工處理、帳號驗證和售後服務等成本，但具體金額仍應以平台付款頁為準。

### 4. 訂閱週期

單月、多月和年付不能只用月均價格比較。月均便宜的方案，可能要求一次支付更多費用，或具有不同的取消規則。

## 哪一種 Claude 方案適合你？

可以用這個簡單結論：

- **只想試用 Claude**：先用 Free。
- **固定寫作、研究、翻譯或編程**：Pro 月付通常是合理起點。
- **確定全年都會使用**：比較官方 Pro 年付 200 美元。
- **常遇到 Pro 使用量限制**：再考慮 Max 5x。
- **每天重度依賴 Claude 完成工作**：才有必要評估 Max 20x。
- **公司多人共同使用**：看 Team，而不是購買多個個人 Pro。
- **需要企業採購、管理與合約支援**：直接詢問 Enterprise。

如果你在意的是「Claude Pro 價格最低是多少」，答案是官方月付 20 美元，年付平均每月約 16.67 美元。但如果你真正的問題是「沒有海外信用卡，怎麼付比較方便」，那麼第三方代訂平台的重點就不只是價格，還包括帳號驗證方式、Cookie 處理、退款條件和後續續訂規則。

購買前先確認三件事：你要的是 Pro 還是 Max、你需要月付還是多月方案，以及付款頁最後顯示的實付金額。這三項確認清楚，通常就能避開大部分訂閱上的麻煩。
